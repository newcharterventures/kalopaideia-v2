# Kalopaideia

*A daily book of words · ten tongues.*

Kalopaideia is a small Node/Express site for people who want a quiet
daily encounter with the classical languages. Each morning a single
word arrives from each tradition — with its inflection, pronunciation,
etymology, the literature it came from, and a short cultural vignette.

Live at: <https://newcharterventures.com/paideia/>

The sister site is **[The Reading Mansion](https://github.com/newcharterventures/the-reading-mansion)**.
One sign-in works at both. One Akousma subscription unlocks the classical
works at both.

---

## What's in the daily book

Ten tongues, in the order they appear:

| Language | Period | Sample sources |
|---|---|---|
| **Greek** | Ancient (Attic/Ionic/Aeolic) | Homer, Plato, Sappho, Sophocles |
| **Latin** | Classical | Cicero, Virgil, Ovid, Horace, Tacitus, Catullus |
| **French** | Pre-1960 literary | Molière, Hugo, Flaubert, Proust, Ronsard, Villon |
| **German** | Pre-1960 letters & philosophy | Goethe, Schiller, Hölderlin, Kant, Heine, Rilke, Nietzsche |
| **Italian** | Medieval / Renaissance | Dante, Petrarch, Boccaccio, Tasso |
| **Old English** | Anglo-Saxon | Beowulf, the Wanderer, Caedmon, Bede |
| **Middle English** | Late medieval | Chaucer, the Pearl-poet, Langland |
| **Welsh** | Medieval (Mabinogi) | Pwyll, the Four Branches |
| **Old Norse** | Eddic / saga | Hávamál, Völuspá, Eddic poetry |
| **Gaulish** | Gallo-Roman epigraphy | Coligny calendar, votive tablets |

Each entry shows the headword, transliteration, part of speech, meaning,
pronunciation (Edge TTS + IPA), a letter-by-letter phonetic breakdown, the
word's principal forms, etymology, literary context, a usage example with
audio, and a "Did You Know" vignette.

## The Akousma

Beyond the daily word, Kalopaideia hosts **The Akousma** — the line-by-line
audio library of full classical works in their original languages with
parallel English translation and a word-by-word gloss on click.

- 22 works across the ten languages: Homer's Iliad I + II + Proem and
  Odyssey I, Plato's Republic I, Sappho 1, Virgil's Aeneid I + Proem,
  Catullus 85, Cicero's *In Catilinam* I, Ronsard, Villon, Goethe's
  *Erlkönig*, Heine's *Lorelei*, Dante's Inferno I, Beowulf prologue,
  the Wanderer, Cædmon's Hymn, Chaucer's General Prologue, Pwyll Prince
  of Dyfed, Hávamál stanzas 1–10, a Gaulish epigraphy primer.
- $11.99/month subscription unlocks every work here AND at The Reading
  Mansion. One subscription, both sites.
- **Odyssey Book 1** is the free gateway; any signed-in user can open it.
- Audio is line-by-line. Each English line has its own audio + a gloss
  popover with morphology and notes.

## Tech

- **Node 20+** (ESM via `"type": "module"`)
- **Express 4** serving the homepage, language pages, archive, library,
  and commerce/auth endpoints
- **better-sqlite3** for local SQLite (sessions, analytics, holdings)
- **Supabase JS** for the shared identity layer
- **Stripe** for the Akousma subscription + per-book purchase webhooks
- **Python 3** (the daily-words pipeline + Edge TTS audio generation)
- **edge-tts** for Microsoft Neural voices (per-language voice tuning in
  `pipeline/voices.py`)

No build step. The front-end is hand-written HTML + CSS + ES-module JS
served from `public/`.

## Running locally

```bash
git clone https://github.com/newcharterventures/paideia.git
cd paideia
cp .env.example .env             # fill in keys (see below)
npm install
pip install edge-tts             # for the audio pipeline
npm start                        # node server.js — defaults to port 3026
```

Open <http://localhost:3026/paideia/>.

The site renders from JSON on disk under `data/`; you need at least
one day of words in `data/words/<YYYY-MM-DD>.json` plus matching
audio in `data/audio/<YYYY-MM-DD>/*.mp3` to see anything. The
content pipeline below produces both.

## Content pipeline

Daily words + culture + audio are generated by a Python pipeline:

```bash
cd pipeline
python3 generate.py              # writes data/words/YYYY-MM-DD.json
python3 audio.py                 # writes data/audio/YYYY-MM-DD/<lang>.mp3
python3 culture.py               # writes data/culture/YYYY-MM-DD.json
```

A typical morning run:

```bash
python3 pipeline/generate.py && \
  python3 pipeline/audio.py && \
  python3 pipeline/culture.py
```

Voices for each language live in `pipeline/voices.py` — Edge TTS doesn't
support classical languages natively, so each picks the closest modern
voice with rate/pitch tuned to evoke the register (Italian for Latin,
Modern Greek for Ancient Greek, etc.).

## Architecture

```
                  ┌─────────────────────────────────┐
                  │    Supabase Auth (shared)       │
                  └────────────────┬────────────────┘
                                   │
                  ┌────────────────┴────────────────┐
                  │  Shared accounts DB (SQLite)    │
                  │  ../mansion/data/shared/        │
                  │       accounts.db               │
                  │  - users, holdings, subs        │
                  └─────────┬─────────────┬─────────┘
                            │             │
                            ▼             ▼
   ┌──────────────────────┐    ┌──────────────────────┐
   │     Kalopaideia      │    │  The Reading Mansion │
   │     /paideia/        │    │    /mansion/         │
   │  data/paideia.db     │    │   data/mansion.db    │
   └──────────────────────┘    └──────────────────────┘
              └──── Shared Akousma catalog ──────────┘
                   ../mansion/data/stoa/library/
```

The classical-works catalog lives in the Mansion repo at
`data/stoa/library/`; Kalopaideia reads it via `MANSION_STOA_DIR`
environment pointer. The shared accounts DB is at
`MANSION_ACCOUNTS_DB`. The mansion side is the authoritative writer
for both.

Cover-art metadata for every work in the Akousma lives in this repo at
`data/library/library-meta.json` and is served via
`GET /api/akousma/cards` and `GET /api/library/:lang` — single source of
truth, no cover URL duplicated client-side.

## Configuration

All configuration is via `.env`. See `.env.example` for the full list.
Key environment variables:

| Env var | Purpose |
|---|---|
| `PORT` | Server port (default 3026 in production) |
| `ANTHROPIC_API_KEY` | For the daily-words pipeline (Claude Sonnet) |
| `SESSION_SECRET` | Express-session signing key |
| `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Shared auth |
| `MANSION_ACCOUNTS_DB` | Path to the shared accounts SQLite file |
| `MANSION_STOA_DIR` | Path to the Akousma library JSON tree |
| `STRIPE_SECRET_KEY` | `sk_live_...` / `sk_test_...` — gates Subscribe buttons |
| `STRIPE_WEBHOOK_SECRET` | `whsec_...` for the webhook signature check |

Until `STRIPE_SECRET_KEY` is set, every Subscribe button across the site
renders as **"Subscribe — coming soon"** (disabled). The flip to live
forms is automatic on the next service restart with the env var present.

## Production

Runs on a single droplet behind nginx at `newcharterventures.com/paideia`.
Service is managed by systemd (user unit):

```bash
systemctl --user status kalopaideia    # check status
systemctl --user restart kalopaideia   # restart
journalctl --user -u kalopaideia -f    # live logs
```

The unit auto-restarts on crash. Nginx config lives at
`/etc/nginx/sites-enabled/default`.

## Hard-won editorial rules

Two standing rules govern this project, both kept in
`~/.openclaw/workspace/MEMORY.md` and mirrored to per-site skills:

1. **PD only.** Every translation, image, audio source, and quotation
   is in the public domain or a license that permits unrestricted
   editorial use. Translations are pre-1929 by default. Images are
   verified PD via Wikimedia Commons API + author death year. No
   AI-generated images.

2. **Cover art must be beautiful, painterly, museum-grade.** Salon-era
   oil, Pre-Raphaelite, Romantic landscape, Old Master, Symbolist —
   yes. Archaeological photos, manuscript folios, bronze fragments,
   coins, tourist site snapshots — no. Every cover is vision-audited
   against seven rules (museum-grade painterly, not scary/ghoulish,
   not nightmarish, not dark-hued, symmetrical composition, full
   color no B&W, PD-only). Detailed rules + safelist + no-list at
   `~/.openclaw/workspace/skills/paideia-covers/SKILL.md`.
